SCuBAAnywhere

CISA's SCuBA baselines, run in your browser. Sign in, collect, read the report, wipe the session.

Assess a Microsoft 365 tenant

You are signed in as yourself, with your own read-only admin rights. Tokens stay in this tab's memory, the configuration is evaluated here, and nothing is stored on a server.

Evaluate a settings export you already have

Point this at a ProviderSettingsExport.json from ScubaGear or the equivalent from ScubaGoggles. The file is read in the page and is not uploaded.

Run log

SCuBAAnywhere is not a CISA project. It runs the Rego policies and baselines published by cisagov/ScubaGear and cisagov/ScubaGoggles, unchanged.
